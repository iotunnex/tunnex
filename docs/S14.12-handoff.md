# 6. THE LAWS THAT KEPT FIRING — the short list

- **A composite result reported by its most favourable component** — in space (typecheck vs test count) and in
  time (an error one scroll back). Report every leg.
- **A mutation that failed to apply proves nothing, and looks exactly like one that was caught.** Before
  reading a guard's verdict, **confirm the mutation changed the subject.** Fourth instance of a check
  reporting on a state it never reached.
- **Run a sweep against a case you already know the answer to.** If the known case is missing, the sweep is
  measuring something else. (A path manifest made "the string appears" correct-by-construction for the wrong
  question.)
- **The artifact outlives the source that produced it** — a running container is not evidence its definition is
  on your branch. Three instances.
- **A threshold should measure the property that matters, not a proxy** — coverage, not N; class tokens, not
  substrings.
- **A wrong direction is worse than not having looked**, because it sends the fix to the wrong file.
- **An animation and a semantic encoding must not share a property** — the cascade favours the animation and
  the meaning fails silently.
- **A view-model with green tests and no caller is invisible to every gate we own.** Grep the ARTIFACT for a
  string only its consumer can produce; tree-shaking is the tell.
- **Writing a rule creates the feeling of having complied with it.** Ask *what in this change is asserted only
  in prose?*
