# 3. WRITE-ONLY STATE — 3, not 37

The first census returned **37 paths with a mutation and no GET** — and it over-reported, the same shape as the
`edition.ts` sweep one story earlier. **`login`, `logout`, `signup`, `verify-email`, `approve`, `revoke`,
`deactivate` are ACTIONS; a GET would be meaningless.**

> ## **THE DISCRIMINATOR IS WHETHER THE THING WRITTEN PERSISTS AS STATE. An action with no readback is**
> ## **correct. CONFIGURATION with no readback is a state the operator can create and never verify.**

**The three:** `POST …/domains` · `PUT …/pool-cidr` · `PUT …/idp-sync/{provider}`.
*(Caught before it shipped as a 37-item backlog row.)*

a server story; naming it on the panel (*"set, not readable back"*) is honest and cheap.
**D4 — machine credentials / edition shedding.** Recommend: **stay, with register rows** — destinations do not
exist.
